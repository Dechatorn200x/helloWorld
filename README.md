# 🚀 Python Hello World ASCII Art Project

ยินดีต้อนรับสู่โปรเจกต์ **Python Hello World ASCII Art**! โปรเจกต์ขนาดเล็กที่เขียนด้วยภาษา Python เพื่อแสดงผลข้อความคำว่า "HELLO" ในรูปแบบตัวอักษรบล็อกขนาดยักษ์ (ASCII Art) พร้อมกับรูปจรวดอวกาศสุดเท่ผ่านทาง Terminal/Console

## 📋 รายละเอียดโปรเจกต์

โปรเจกต์นี้สาธิตการใช้โค้ด Python ขั้นพื้นฐานในการจัดการและแสดงผลข้อความหลายบรรทัด (Multi-line strings) โดยใช้ Raw String (`r'''...'''`) เพื่อรักษารูปแบบของตัวอักษรพิเศษและช่องว่าง (Whitespace) ให้คงเดิมอย่างถูกต้อง เหมาะสำหรับผู้เริ่มต้นศึกษาภาษา Python ที่ต้องการเห็นผลลัพธ์การรันโค้ดที่สวยงามและสร้างสรรค์

## 🚀 คุณสมบัติ (Features)

- แสดงคำว่า **HELLO** ขนาดใหญ่ในรูปแบบ ASCII Art
- แสดงอิโมจิและข้อความ `🚀 HELLO WORLD 🚀`
- แสดงรูป**จรวดพ่นไฟ (Rocket)** สลักคำว่า `PYTHON` สุดคูล
- โค้ดอ่านง่าย โครงสร้างไม่ซับซ้อน เหมาะสำหรับการเรียนรู้
